# prompts/

AI prompts used by the project.

- `stitch/` — per-screen Google Stitch design briefs, written in Phase 2 from
  `.ai/design-system.md`. One file per screen (`prompts/stitch/<screen>.md`),
  each stating: purpose, breakpoints, tokens to use, components to reuse,
  content/states (loading/empty/error), interaction + motion notes,
  accessibility + reduced-motion requirements, and the Flathub/Modrinth
  reference for that screen.
