Fedora is where much of the Linux desktop's future ships first. Backed by
Red Hat and built by a large community, it delivers a new release roughly
every six months with the latest stable GNOME, kernel, and developer
toolchains — while staying reliable enough for daily work.

Fedora leads with upstream-first engineering: changes land in the original
projects rather than as local patches, so what you run is close to what the
wider ecosystem will run next.

## Editions

Workstation (GNOME) is the flagship desktop. Spins cover KDE Plasma, Xfce,
and other desktops; Server targets headless machines; and the Atomic
desktops (such as Silverblue) offer image-based systems where updates apply
as a whole and roll back cleanly.
