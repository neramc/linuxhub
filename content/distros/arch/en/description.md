Arch is a rolling-release distribution you assemble yourself: a minimal
base, the `pacman` package manager, the AUR's enormous user-maintained
repository, and the best documentation in Linux — the ArchWiki.

There is no installer holding your hand by default and no release schedule;
packages flow continuously from upstream, so your system is always current.
The trade is responsibility: you read the news before big updates, and you
understand the system because you built it.

## What "editions" means here

There's one ISO — a bootable environment from which you install the system
you want, either manually per the wiki's Installation Guide or with the
bundled `archinstall` helper. Everything after that (desktop, services,
extras) is your choice.
