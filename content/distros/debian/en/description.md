Debian is the universal operating system — the volunteer-run project whose
stable releases and packaging culture underpin hundreds of derivatives,
Ubuntu included.

Stable trades novelty for rock-solid predictability: releases arrive
roughly every two years, change little in between, and receive security
support long after. That's why it runs so much of the world's server fleet
— and why a Debian desktop feels calm rather than current.

## Branches

**Stable** is the release; **testing** is the next release forming;
**unstable (sid)** is where uploads land first. Desktops wanting fresher
software sometimes run testing, accepting occasional breakage that stable
by definition avoids.
