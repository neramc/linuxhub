Ubuntu is the most widely deployed desktop Linux, built on Debian with a
predictable rhythm: a long-term support (LTS) release every two years with
five years of standard updates, and interim releases every six months in
between. Canonical, the company behind it, also ships Server, Cloud, and
IoT variants from the same base.

Its size is the point — hardware vendors test against it, commercial
software ships `.deb` packages for it, and nearly every tutorial on the
internet assumes it. If you want the path most traveled, this is it.

## Editions

The Desktop edition ships GNOME. Official flavors swap the desktop while
keeping the same archive underneath: Kubuntu (KDE Plasma), Xubuntu (Xfce),
Ubuntu MATE, and others. Ubuntu Server drops the desktop entirely.
