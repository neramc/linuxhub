Pop!_OS is System76's desktop built on Ubuntu, known for keyboard-driven
auto-tiling window management, first-class NVIDIA support (a dedicated ISO
ships the proprietary driver preinstalled), and sensible developer
defaults.

Its newer releases center on **COSMIC**, System76's own desktop environment
written in Rust — tiling, workspaces, and launcher are native features
rather than extensions.

## Editions

Two ISOs: Intel/AMD, and NVIDIA with the driver baked in. Both carry the
same system underneath; pick by GPU and everything else is identical.
