Linux Mint takes Ubuntu's LTS base and wraps it in the Cinnamon desktop — a
layout Windows users recognize immediately, with media codecs and sensible
defaults included out of the box.

Updates are conservative on purpose: Mint prioritizes not breaking your
machine over shipping the newest bits, and its Update Manager pairs with
built-in Timeshift snapshots so the system can always step back to a known
good state.

## Editions

Cinnamon is the flagship. MATE and Xfce editions offer the same system with
lighter desktops for older hardware. All three track the current Ubuntu LTS
and are supported until that LTS retires.
