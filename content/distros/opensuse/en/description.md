openSUSE offers two tracks from one project: **Leap**, a stable release
aligned with SUSE's enterprise base, and **Tumbleweed**, a rolling release
that is openQA-tested before updates reach you — unusually careful for a
rolling model.

**YaST**, its configuration center, remains the most complete admin tool
shipped by any distribution: partitioning, services, network, and software
management under one roof. Btrfs snapshots via Snapper are wired in by
default, so updates come with an undo button.

## Editions

Leap for set-and-forget machines; Tumbleweed for current software with
automated QA; MicroOS for immutable, container-focused hosts. KDE Plasma is
the most polished desktop choice, with GNOME and others available at
install time.
