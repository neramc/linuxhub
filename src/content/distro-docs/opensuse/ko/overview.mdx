openSUSE는 openSUSE 프로젝트가 만드는 커뮤니티 배포판으로, 성격이 다른 두 배포판을 함께 냅니다. Tumbleweed는 따로 버전을 올릴 필요 없이 계속 새 패키지를 받는 롤링 릴리스이고, Leap은 SUSE Linux Enterprise(SLE)의 소스에 커뮤니티 개발을 더한 고정 릴리스입니다. 두 배포판 모두 패키지는 RPM 형식이고 `zypper`로 관리합니다.

### 특징

- **시험을 거친 롤링 릴리스.** Tumbleweed는 새 커널과 드라이버, 데스크톱을 빠르게 받으면서도, 패키지를 하나씩 시험하는 데 그치지 않고 여러 패키지를 묶어 서로 맞는지 확인한 뒤 스냅숏으로 내보냅니다.
- **스냅숏으로 되돌리기.** Btrfs 파일 시스템과 Snapper를 쓰면 소프트웨어를 설치하거나 업데이트할 때마다 자동으로 스냅숏이 남습니다. 업데이트 뒤 문제가 생기면 이전 스냅숏으로 부팅해 몇 분 안에 원래 상태로 돌아갈 수 있습니다.
- **SLE를 바탕으로 한 Leap.** Leap은 해마다 새 마이너 버전이 나오고 각 버전은 24개월 동안 업데이트를 받습니다. 더 긴 지원이 필요하면 openSUSE 마이그레이션 도구로 SUSE Linux Enterprise로 옮길 수 있습니다.
- **모두 공개된 빌드.** 배포판에 들어가는 모든 패키지의 소스와 빌드 스크립트가 Open Build Service에 공개되어 있습니다. 자유 소프트웨어와 비자유 소프트웨어는 저장소가 나뉘어 있어 비자유 저장소를 끌 수 있습니다.

### 에디션과 변형

- **Tumbleweed**와 **Leap**이 데스크톱과 서버용 주력 배포판입니다. 설치할 때 데스크톱을 고르며, 프로젝트는 KDE Plasma, GNOME, Xfce 세 가지를 중심으로 지원합니다.
- **MicroOS**는 읽기 전용 Btrfs 루트에 트랜잭션 업데이트를 적용하는 불변(atomic) 롤링 배포판으로, 컨테이너 작업을 돌리는 데 맞춰져 있습니다.
- **Leap Micro**는 SUSE Linux Micro를 바탕으로 한 불변 배포판으로, 컨테이너와 가상화 작업을 위한 가벼운 시스템입니다.

### 이런 분께 맞습니다

- 최신 소프트웨어를 쓰면서도 문제가 생기면 쉽게 되돌리고 싶은 개발자와 게이머(Tumbleweed)
- 안정성을 중시하는 시스템 관리자와 엔터프라이즈 개발자, 일반 데스크톱 사용자(Leap)
- 나중에 SUSE Linux Enterprise로 옮길 가능성이 있는 서버

### 알아 둘 점

- Leap 16부터 새 설치 프로그램 Agama를 쓰고, 시스템 관리는 YaST 대신 웹 기반 Cockpit으로 합니다.
- Leap 16은 x86-64-v2 이상 CPU가 필요하고 64비트 프로그램만 지원합니다. 32비트 라이브러리 문제로 Steam은 Flatpak으로 설치하도록 안내합니다.
- Leap 16 설치 프로그램은 데스크톱의 Wayland 세션만 제공하고, Xorg 기반 환경은 설치 뒤 직접 추가해야 합니다. 새로 설치할 때 보안 모듈로 AppArmor를 고를 수도 없습니다.
- 스냅숏을 쓰려면 루트 파티션을 40GB 이상으로 잡는 것이 좋습니다.

### 간단한 역사

openSUSE 프로젝트는 2005년 8월 9일에 시작되어 2025년에 20주년을 맞았습니다. Leap 16.0은 openSUSE를 만드는 방식을 새로 바꾼 버전으로, 각 버전의 지원 기간이 24개월로 늘었습니다.
