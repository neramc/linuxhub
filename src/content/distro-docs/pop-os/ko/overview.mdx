Pop!_OS는 미국의 컴퓨터 제조사 System76이 직접 만드는 Ubuntu 기반 배포판입니다. Ubuntu LTS 버전에 맞춰 나오는 고정 릴리스이며, 지금 최신 버전은 Pop!_OS <Latest slug="pop-os" />입니다. 24.04 LTS부터는 System76이 Rust로 새로 만든 COSMIC 데스크톱 환경을 기본으로 씁니다.

### 특징

- **직접 만든 COSMIC 데스크톱.** 패널과 독의 배치, 색과 테마를 설정에서 바로 바꿀 수 있고, 파일 관리자와 터미널, 텍스트 편집기, 앱 스토어 같은 기본 앱도 COSMIC용으로 새로 만들었습니다. 모듈식으로 설계되어 다른 프로젝트가 가져다 쓸 수도 있습니다.
- **타일링과 작업 공간.** 패널의 스위치 하나로 자동 타일링을 켜고, 마우스로 끌거나 키보드 단축키로 창을 배치합니다. 작업 공간을 디스플레이마다 따로 두거나 고정할 수 있고, 고해상도 화면과 일반 화면을 섞어 써도 배율을 알아서 맞춥니다.
- **하드웨어 회사의 배포판.** NVIDIA 드라이버를 미리 넣은 ISO를 따로 내고, 노트북의 하이브리드 그래픽에서는 외장 GPU를 요청하는 앱을 알아서 그 GPU로 실행합니다. 커널과 하드웨어 지원은 릴리스 중에도 계속 새로 갱신됩니다.
- **APT와 Flatpak.** Ubuntu에서 돌아가는 소프트웨어는 Pop!_OS에서도 쓸 수 있고, COSMIC Store에서는 Flathub 앱도 설치합니다. 부팅할 때 Space 키를 누르거나 ISO로 시작하면 파일과 설정을 남긴 채 운영체제만 다시 설치하는 Refresh 기능도 있습니다.

### 에디션과 변형

- 설치 이미지는 그래픽 카드에 따라 고릅니다. Intel·AMD 그래픽과 NVIDIA 10 시리즈 이하는 기본 ISO를, NVIDIA 16 시리즈 이후는 NVIDIA ISO를 씁니다.
- ARM64 컴퓨터용 ISO와 그 NVIDIA판도 있습니다. System76의 Thelio Astra에서 공식 지원하며, 다른 ARM 기기는 Tow-Boot를 통한 커뮤니티 지원입니다.

### 이런 분께 맞습니다

- 타일링 창 관리를 마우스와 키보드로 부담 없이 써 보고 싶은 사람
- NVIDIA 그래픽 카드로 게임이나 작업을 하는 사용자
- 여러 모니터를 오가며 일하는 사람과 System76 컴퓨터 사용자

### 알아 둘 점

- 설치하기 전에 BIOS에서 Secure Boot를 꺼야 합니다.
- 기본 ISO로 설치한 뒤 NVIDIA 카드를 쓰려면 `sudo apt install system76-driver-nvidia`로 드라이버를 따로 설치합니다.
- COSMIC은 아직 새 데스크톱이라 디스플레이 전환 단축키 같은 일부 기능이 빠져 있고, 터치 기기에는 최적화되지 않았습니다. 기능은 업데이트로 계속 더해집니다.
- 22.04는 설정의 OS Upgrade & Recovery나 `pop-upgrade release upgrade`로 24.04에 올릴 수 있으며, 최대 한 시간쯤 걸립니다. 22.04보다 오래된 버전은 새로 설치하기를 권합니다.

### 간단한 역사

System76은 자사 하드웨어와 소프트웨어를 하나의 제품으로 맞추려고 운영체제를 직접 만들기로 했고, 2017년 Ubuntu 17.10을 바탕으로 한 첫 버전 17.10을 내놓았습니다. 18.04에서 자체 설치 프로그램을, 20.04에서 자동 타일링을 들였고, 3년 넘는 개발 끝에 2025년 12월 24.04 LTS와 함께 COSMIC 데스크톱 환경을 공개했습니다.
