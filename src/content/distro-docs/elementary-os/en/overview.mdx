elementary OS is an Ubuntu LTS–based distribution made by elementary, Inc. in the United States. What sets it apart is that the desktop and the core apps are designed in-house, so the whole system follows one design. It is a fixed release; the current version is elementary OS <Latest slug="elementary-os" />.

### Highlights

- **Pantheon, designed in-house.** Pantheon is elementary's own desktop environment, recognized by FreeDesktop.org. It consists of a top panel, a dock at the bottom and the Gala window manager, and the core apps, including Files, Terminal, Mail, Calendar and the Code editor, are written by the team to the same design guidelines.
- **A Secure Session that asks first.** OS 8 introduced the Wayland-based Secure Session, and since 8.1 it is the default. Apps must ask before using system features such as taking screenshots, and while a password dialog is open no other window can steal its focus.
- **AppCenter and Flathub.** AppCenter is a pay-what-you-can store of Flatpak apps reviewed by elementary. Since OS 8, Flathub is included out of the box for cross-platform apps, and apps made specifically for elementary OS carry their own badge.
- **Two kinds of updates.** System updates come from System Settings and install when you restart; app updates come from AppCenter and never need a restart. Updates arrive monthly, and since 8.1.1 automatic updates are on by default.

### Who it suits

- People who want a tidy desktop with a consistent design
- Anyone who wants to manage app permissions and privacy directly
- Families who want to limit screen time, apps and websites for a child's account
- Users who like to pay independent developers for their apps

### Good to know

- The download is pay what you can: you pick the amount. That income, not advertising or data collection, funds development.
- The set of default apps is kept small on purpose. Install anything else, such as an office suite, from AppCenter or Flathub.
- If an older app misbehaves in the Secure Session, choose the Classic Session from the gear menu on the lock screen.
- ARM64 builds arrived with 8.1 and are for devices that boot with UEFI, such as Apple Silicon M-series Macs or a Raspberry Pi running UEFI firmware.
- The kernel follows Ubuntu's LTS hardware enablement (HWE) stack, so point releases bring newer kernels.

### A short history

The first version, 0.1 “Jupiter”, came out in March 2011 on Ubuntu 10.10 with a GNOME 2 desktop. Pantheon debuted in 2012 with 0.2 “Luna”, and with 5 “Juno” in 2018 the project dropped the 0.x numbering.
