elementary OS는 미국의 elementary, Inc.가 만드는 Ubuntu LTS 기반 배포판입니다. 데스크톱과 기본 앱을 직접 설계해 처음부터 끝까지 한 가지 디자인으로 맞춘 것이 가장 큰 특징입니다. 고정 릴리스 방식이며, 지금 최신 버전은 elementary OS <Latest slug="elementary-os" />입니다.

### 특징

- **직접 설계한 Pantheon.** Pantheon은 FreeDesktop.org가 인정한 elementary의 독자 데스크톱 환경입니다. 위쪽 패널과 아래쪽 독, 창 관리자 Gala로 이루어지고, 파일, 터미널, 메일, 캘린더, 코드 편집기 같은 기본 앱도 직접 만들어 같은 디자인 규칙을 따릅니다.
- **동의를 먼저 묻는 Secure Session.** OS 8에서 Wayland 기반의 Secure Session을 들였고, 8.1부터 이것이 기본 세션입니다. 앱이 화면 캡처 같은 시스템 기능을 쓰려면 먼저 허락을 받아야 하고, 비밀번호 창이 떠 있는 동안에는 다른 창이 입력을 가로챌 수 없습니다.
- **AppCenter와 Flathub.** AppCenter는 elementary가 검토한 Flatpak 앱을 원하는 만큼 값을 치르고 받는 앱 스토어입니다. OS 8부터는 Flathub도 기본으로 들어 있어 여러 플랫폼용 앱을 함께 설치할 수 있고, elementary OS를 위해 만든 앱에는 따로 배지가 붙습니다.
- **나뉜 업데이트.** 운영체제 업데이트는 시스템 설정에서 받아 재시작할 때 설치하고, 앱 업데이트는 AppCenter에서 재시작 없이 설치합니다. 업데이트는 매달 나오며, 8.1.1부터 자동 업데이트가 기본으로 켜져 있습니다.

### 이런 분께 맞습니다

- 단정하고 일관된 디자인의 데스크톱을 원하는 사람
- 앱 권한과 개인 정보를 직접 관리하고 싶은 사람
- 자녀 계정의 사용 시간과 앱, 웹사이트를 제한하려는 가족
- 독립 개발자가 만든 앱을 쓰고 직접 후원하고 싶은 사람

### 알아 둘 점

- 내려받을 때 금액을 직접 정하는 pay what you can 방식입니다. 광고나 데이터 수집 대신 이 수익으로 개발합니다.
- 기본 앱은 일부러 적게 넣었습니다. 사무용 프로그램 같은 다른 앱은 AppCenter나 Flathub에서 더 설치합니다.
- 오래된 앱이 Secure Session에서 제대로 동작하지 않으면 로그인 화면의 톱니바퀴 메뉴에서 Classic Session을 고를 수 있습니다.
- ARM64판은 8.1에서 처음 나왔으며 UEFI로 부팅하는 기기용입니다. M 시리즈 Apple Silicon Mac이나 UEFI 펌웨어를 올린 Raspberry Pi에서 쓸 수 있습니다.
- 커널은 Ubuntu LTS의 HWE(하드웨어 지원) 스택을 따라가므로 포인트 릴리스마다 새로워집니다.

### 간단한 역사

첫 버전 0.1 "Jupiter"는 2011년 3월, Ubuntu 10.10을 바탕으로 GNOME 2 데스크톱을 써서 나왔습니다. 2012년 0.2 "Luna"에서 Pantheon을 처음 선보였고, 2018년 5 "Juno"부터 0.x 대신 정수 버전 번호를 씁니다.
