Lubuntu is the official Ubuntu flavor with LXQt, a lightweight desktop built on Qt. Its goal is a light but fully usable system on a solid Ubuntu base, released on Ubuntu’s schedule: a new version every six months and a long-term support (LTS) release every two years. The current version is Lubuntu <Latest slug="lubuntu" />.

### Highlights

- **LXQt on Qt 6.** The desktop and its apps run on Qt 6, and Kvantum as the theme engine keeps Qt apps looking consistent. The application menu is LXQt’s newer Fancy Menu.
- **The apps you need.** Firefox (as a snap), LibreOffice, VLC and the light FeatherPad editor cover browsing, mail, documents and media, and the other bundled tools are chosen to stay out of your way.
- **Discover for software.** KDE’s Discover software center installs and updates both deb packages from the Ubuntu archive and snaps.
- **Live ISOs and Calamares.** Every ISO is a live image you can try before installing, and installation runs through Calamares. A Lubuntu Manual icon on the desktop opens the user guide.

### Who it suits

- Owners of older or low-memory PCs that find Ubuntu Desktop too heavy; Ubuntu’s own release notes point lower-spec machines to the flavors and say Lubuntu installs on 2 GB of RAM or more
- People who want Qt and KDE apps on a light desktop
- Users who want a simple desktop with Ubuntu’s archive and release schedule underneath

### Good to know

- LTS releases are supported for three years, shorter than Ubuntu Desktop’s five; interim releases get nine months.
- The default session is still X11. Since 26.10 an experimental Wayland session using the Miriway compositor can be picked on the login screen, and the team says there are no plans to drop X11 for now.
- Recent releases have known issues, such as KWallet being installed instead of gnome-keyring and Alacritty arriving alongside QTerminal, so check the known issues in the release announcement first.

### A short history

Lubuntu joined Ubuntu’s official releases with Ubuntu 11.10 in October 2011; Julien Lavergne founded the project. The 26.04 LTS release in April 2026 was Lubuntu’s 30th, and its 16th with LXQt as the default desktop.
