Q4OS는 Debian을 바탕으로 한 가볍고 쓰기 쉬운 데스크톱 배포판으로, 체코 프라하에 개발 거점을 둔 팀이 만듭니다. Debian 안정판 위에 장기 지원(LTS) 릴리스를 내고 몇 달마다 점 버전으로 설치 이미지를 새로 고치며, 지금 최신 버전은 Q4OS <Latest slug="q4os" />(<Latest slug="q4os" field="codename" />)입니다.

### 특징

- **오래 그대로 두는 시스템.** 데스크톱 환경과 대부분의 도구는 처음 실린 메이저 버전을 유지하고 보안 수정만 받습니다. 새 기능은 아주 예외적으로만 들입니다. 대신 앱은 Flatpak으로 새 버전을 쓸 수 있습니다.
- **필요한 것만 까는 Desktop profiler.** 처음부터 앱을 가득 채우지 않고, "프로필"이라는 앱 묶음을 골라 한 번에 설치합니다. 지금 시스템을 프로필로 내보냈다가 다른 PC에 설치할 때 Calamares 설치 프로그램에서 불러올 수도 있습니다.
- **Plasma와 Trinity를 나란히.** 기본 데스크톱은 KDE Plasma이고 겉모습도 원래 모습 그대로 둡니다. 여기에 가벼운 Trinity 데스크톱을 서로 간섭하지 않게 함께 설치해 두고, 로그인할 때마다 골라 쓸 수 있습니다.
- **Windows 안에 설치.** Windows에서 설치 마법사를 실행하면 파티션을 나누지 않고 Windows 드라이브의 폴더 하나에 Q4OS가 설치됩니다. 가상 머신이 아니라 부팅할 때 골라 실제 하드웨어 위에서 돌아갑니다.
- **긴 지원 기간.** LTS 릴리스는 5년 동안 보안 패치와 업데이트를 받으며, 지금 버전은 적어도 <Latest slug="q4os" field="eol" />까지 지원됩니다.

### 에디션과 변형

- **Plasma live**가 기본 판이고, 같은 LTS를 **Trinity live**로도 받을 수 있습니다. 오래된 PC에는 Trinity **install-cd** 판을 권합니다.
- **Windows용 설치 프로그램**(WinSetup)은 Windows 11, 10, 8, 7에서 실행합니다.
- 64비트 ARM 기기(Chromebook, 태블릿, 싱글보드 컴퓨터 등)용 Trinity 판이 따로 있고, Raspberry Pi용 비공식 판은 비공식 저장소에서 제공합니다.

### 이런 분께 맞습니다

- 사양이 낮거나 오래된 PC를 가벼운 데스크톱으로 계속 쓰고 싶은 사람
- 파티션을 건드리지 않고 Windows 옆에 Linux를 두고 싶은 Windows 사용자
- 한 번 설정하면 몇 년 동안 손이 덜 가는 시스템을 원하는 개인과 회사
- 여러 대의 PC에 같은 앱 구성을 빠르게 깔아야 하는 관리자

### 알아 둘 점

- 현재 LTS에는 32비트 판이 없습니다. 32비트 PC에는 2028년 6월까지 지원되는 이전 LTS의 32비트 install-cd를 씁니다.
- Secure Boot는 기본으로 지원합니다. 다만 Windows용 설치 프로그램으로 설치한 Q4OS가 부팅되지 않으면 펌웨어에서 Secure Boot를 Audit 모드로 바꾸거나 꺼야 할 수 있습니다.
- Windows용 설치 프로그램은 BitLocker로 암호화한 드라이브를 지원하지 않습니다. 또 일부 PC는 펌웨어가 Windows 부트로더만 보여 주므로, 부팅할 때 기능 키로 부팅 메뉴를 열어 Q4OS를 골라야 합니다.
- Q4OS 전용 테마가 보고 싶다면 시스템 설정에서 Debonaire 테마로 바꾸거나 Lookswitcher를 설치합니다.

### 간단한 역사

Q4OS는 2014년에 국제 프로젝트로 시작했고, 이후 개발의 중심이 체코 프라하로 옮겨 갔습니다. Debian 13을 바탕으로 한 Andromeda는 2025년 9월에 나왔고, 같은 해 12월에는 64비트 ARM 기기용 판이 더해졌습니다.
