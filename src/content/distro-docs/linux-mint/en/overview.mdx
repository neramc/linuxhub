Linux Mint is a desktop distribution built on Ubuntu's long-term support (LTS) releases. It aims for a comfortable desktop that works as soon as it is installed and presents itself as an alternative to Windows and macOS. It follows a fixed release model; the current version is Linux Mint <Latest slug="linux-mint" />.

### Highlights

- **The home of Cinnamon.** Cinnamon is Linux Mint's own desktop. When GNOME 3 took away the panel, menu and tray in 2011, the team built a complete desktop on top of it, and Mint still keeps that traditional layout.
- **Updates with a safety net.** Update Manager separates software, security and kernel updates. The project recommends letting the bundled Timeshift take daily and boot-time snapshots, so a bad update can be undone by restoring the system. Snapshots leave your personal files out.
- **A conservative, LTS-only base.** Since 2014 Mint has built only on Ubuntu LTS releases. Major versions have so far been supported for five years, and moving to a point release within one, such as 22.1, 22.2 or 22.3, takes minutes.
- **APT and Flatpak, not Snap.** Canonical's Snap Store has been blocked by default since Linux Mint 20. Software Manager handles APT packages and Flatpaks, and since Linux Mint 22 it hides unverified Flatpaks by default.

### Editions and variants

- The **Cinnamon edition** is the most popular. The **Xfce edition** does less but is lighter, and the **MATE edition** carries on GNOME 2, Mint's default desktop until 2011.
- **HWE ISOs** put a newer kernel into the same release. Third-party modules such as NVIDIA or VirtualBox may not keep up with it, so use them only when the regular ISO does not work.
- **LMDE** (Linux Mint Debian Edition) is built on Debian instead of Ubuntu, so Mint could carry on with the same experience if Ubuntu ever went away.

### Who it suits

- People moving to Linux from Windows or macOS
- Anyone who wants a familiar desktop with a menu and a panel
- Users who want to install once and keep a stable system for years

### Good to know

- Tick the box in the installer while online and multimedia codecs are installed with the system. If the installed system then fails with a Secure Boot violation, the guide suggests reinstalling without that third-party option or turning Secure Boot off.
- With an NVIDIA card, install the proprietary driver from Driver Manager after installation.
- Cinnamon runs an X11 session by default; Wayland support is still experimental.
- Major upgrades follow fixed paths and can take a few hours. To go from 21 to 22, you first upgrade to 21.3.
- In 2026 the project moved from a six-month to a yearly cycle. From the next release on, versions are to be numbered after the following year (27, then 28) with no point releases.

### A short history

Linux Mint started in 2006 as a website where French developer Clement Lefebvre posted his reviews. Linux Mint 1.0 “Ada”, based on Kubuntu 6.06, followed that August, and 2.0 “Barbara” switched to GNOME in November.
