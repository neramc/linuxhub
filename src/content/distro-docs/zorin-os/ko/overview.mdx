Zorin OS는 아일랜드의 Zorin OS Technologies가 만드는 Ubuntu LTS 기반 데스크톱 배포판입니다. Windows나 macOS를 쓰던 사람이 새로 배우지 않고도 바로 쓸 수 있는 것을 목표로 합니다. 고정 릴리스이며, 지금 최신 버전은 Zorin OS <Latest slug="zorin-os" />입니다.

### 특징

- **익숙한 모양으로 바꾸는 데스크톱.** 기본 데스크톱은 GNOME Shell을 바탕으로 다듬은 것입니다. Zorin Appearance 앱에서 Windows, macOS, Linux 식 배치 가운데 하나를 고르면 화면 구성이 그대로 바뀝니다. 창을 화면 위쪽으로 끌어 미리 정한 배치에 놓는 창 타일링도 18부터 기본으로 들어 있습니다.
- **Windows에서 넘어오는 사람을 위한 도구.** Windows 설치 파일을 실행하면 그 앱의 Linux판이나 비슷한 대체 앱을 먼저 알려 줍니다. 꼭 필요하면 WINE 기반의 Windows App Support로 실행할 수 있고, 웹사이트를 앱처럼 쓰는 Web Apps와 OneDrive 연결도 갖추었습니다.
- **한곳에서 여러 앱 형식을.** 소프트웨어 스토어 하나로 Zorin OS와 Ubuntu의 APT 저장소, Flathub, Snap Store의 앱을 처음부터 설치할 수 있고, AppImage 파일도 더블클릭으로 실행됩니다.
- **휴대폰 연동.** Zorin Connect로 Android 휴대폰과 알림, 메시지, 파일을 주고받습니다. 로컬 네트워크의 암호화된 연결만 쓰므로 데이터가 클라우드를 거치지 않습니다.

### 에디션과 변형

- **Core**는 무료 기본판으로 표준 앱과 네 가지 데스크톱 배치를 담습니다. **Education**도 무료이며 학교와 학생을 위한 교육용 앱과 게임을 더했습니다.
- **Pro**는 한 번 결제하는 유료판입니다. 배치가 열두 가지로 늘고 디자인, 사진, 영상, 오디오용 창작 앱과 생산성 도구, 설치 지원이 붙으며, 판매 수익이 개발비가 됩니다.
- **Lite**는 Xfce를 바탕으로 한 오래되거나 사양이 낮은 컴퓨터용 판입니다. 18 시리즈까지만 나오고 19부터는 공식 에디션에서 빠질 예정입니다.

### 이런 분께 맞습니다

- 지원이 끝난 Windows 10 PC를 계속 쓰고 싶은 사람
- Windows나 macOS와 비슷한 화면에서 Linux를 시작하고 싶은 사람
- 같은 환경을 여러 해 동안 여러 대에 쓰려는 학교와 기관

### 알아 둘 점

- NVIDIA 그래픽 카드라면 부팅 메뉴에서 modern NVIDIA drivers 항목으로 시작해 독점 드라이버와 함께 설치합니다. 드라이버가 제대로 동작하려면 Secure Boot를 먼저 꺼야 할 수 있습니다.
- 64비트 Intel·AMD 프로세서용이라 Apple silicon Mac이나 ARM 기반 Surface에서는 바로 실행할 수 없습니다. Raspberry Pi용 판도 아직 없습니다.
- Core는 15GB면 설치되지만 Education은 35GB, Pro는 45GB의 저장 공간이 필요합니다.
- Zorin OS 17에서는 파일을 지우지 않고 18.1로 바로 업그레이드할 수 있습니다.

### 간단한 역사

Zorin OS는 2008년, 데스크톱에서 Linux가 널리 쓰이지 못한 가장 큰 이유를 쓰기 어려움으로 보고 이를 해결하겠다며 시작했습니다. 개발비는 Pro 구매와 기부, 곧 사용자 커뮤니티의 지원으로만 마련합니다.
