Zorin OS is a desktop distribution built on Ubuntu LTS by Zorin OS Technologies in Ireland. Its aim is a system that people coming from Windows or macOS can use without learning anything new. It is a fixed release; the current version is Zorin OS <Latest slug="zorin-os" />.

### Highlights

- **A desktop that takes a familiar shape.** The default desktop is a customized GNOME Shell. Pick a Windows-, macOS- or Linux-style layout in the Zorin Appearance app and the whole desktop rearranges itself. Since Zorin OS 18, window tiling is built in: drag a window to the top of the screen and drop it onto a predefined layout.
- **Help for people leaving Windows.** Open a Windows installer and Zorin OS first points you to the app's Linux version or a close alternative. When you really need the Windows app, the WINE-based Windows App Support can run it, and Web Apps and OneDrive integration are included too.
- **Many app formats in one place.** The Software store installs apps from the Zorin OS and Ubuntu APT repositories, Flathub and the Snap Store out of the box, and AppImage files run with a double-click.
- **Phone integration.** Zorin Connect syncs notifications and messages and moves files between the computer and an Android phone, over an encrypted connection on the local network rather than through the cloud.

### Editions and variants

- **Core** is the free standard edition, with the usual apps and four desktop layouts. **Education** is also free and adds learning apps and games for schools and students.
- **Pro** is a one-time purchase. It raises the layouts to twelve and adds creative apps for design, photo, video and audio, productivity tools and installation support; sales fund development.
- **Lite** is an Xfce-based edition for older or low-spec computers. It continues through the 18 series and is to be dropped as an official edition from Zorin OS 19.

### Who it suits

- Owners of Windows 10 PCs who want to keep using them after support ended
- Newcomers who want to start Linux on a screen that looks like Windows or macOS
- Schools and organizations that want the same setup on many machines for years

### Good to know

- With an NVIDIA card, choose the modern NVIDIA drivers entry in the boot menu to install with the proprietary driver. You may need to turn off Secure Boot first for the driver to work fully.
- Zorin OS is for 64-bit Intel and AMD processors, so it does not run natively on Apple silicon Macs or ARM-based Surface devices, and there is no Raspberry Pi version yet.
- Core installs in 15 GB of storage, but Education needs 35 GB and Pro 45 GB.
- Zorin OS 17 can be upgraded directly to 18.1 without erasing your files.

### A short history

Zorin OS started in 2008. Its makers saw poor ease of use as the biggest barrier to Linux on desktop computers and set out to fix it. Development is funded entirely by its users, through Pro purchases and donations.
