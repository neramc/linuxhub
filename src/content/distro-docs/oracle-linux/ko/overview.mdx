Oracle Linux는 Oracle이 만드는 엔터프라이즈 배포판으로, Red Hat Enterprise Linux(RHEL)와 사용자 공간이 호환됩니다. 2006년부터 소스와 바이너리, 업데이트를 모두 무료로 내려받아 운영 환경에서 쓰고 재배포할 수 있게 해 왔습니다. 메이저 버전 안에서 업데이트 릴리스가 이어지는 고정 릴리스이며, 지금 최신 버전은 Oracle Linux <Latest slug="oracle-linux" />입니다.

### 특징

- **두 가지 커널.** Oracle이 직접 만드는 Unbreakable Enterprise Kernel(UEK)이 새로 설치할 때의 기본 커널입니다. x86_64에서는 RHEL과 호환되는 Red Hat Compatible Kernel(RHCK)을 골라 쓸 수도 있습니다. 어느 커널을 쓰든 RHEL용 애플리케이션은 고치지 않고 그대로 돌아갑니다.
- **무료로 쓰고 필요할 때 지원 계약.** 배포판과 yum 저장소의 업데이트는 무료입니다. 24시간 기술 지원, 재부팅 없이 커널을 패치하는 Ksplice, KVM 가상화 관리 도구, Kubernetes 환경 같은 것은 유료 지원 구독에 들어 있습니다.
- **긴 지원 기간.** 메이저 버전마다 출시 후 10년 동안 Premier Support를 받을 수 있고, 그 뒤에도 Extended Support와 Lifetime Sustaining Support로 늘릴 수 있습니다.
- **Oracle 클라우드의 기반.** Oracle의 퍼블릭 클라우드가 Oracle Linux 위에서 돌아가며, OCI의 OS Management Hub로 패치를 한곳에서 관리할 수 있습니다.

### 에디션과 변형

- **Full ISO**는 설치에 필요한 모든 것을 담은 이미지입니다.
- **UEK Boot ISO**와 **Boot ISO**는 부팅해서 설치를 시작하는 데 필요한 것만 담은 작은 이미지입니다. 앞의 것은 UEK로, 뒤의 것은 RHCK로 부팅합니다.
- 설치할 때 Server with GUI 환경을 고르면 GNOME 데스크톱이 들어갑니다. 패키지 소스를 모은 Source ISO도 따로 있습니다.

### 이런 분께 맞습니다

- Oracle Database나 Oracle Cloud Infrastructure(OCI)를 함께 쓰는 조직
- RHEL 호환 시스템을 무료로 쓰다가 필요한 서버에만 유료 지원을 붙이고 싶은 곳
- 재부팅 없는 커널 패치처럼 가동 중단을 줄이는 기능이 필요한 운영 환경

### 알아 둘 점

- 무료 yum 서버에는 기술 지원이 없습니다. 도움이 필요하면 Oracle Linux 커뮤니티를 이용하거나 지원 계약을 맺어야 합니다.
- Oracle Linux 10의 x86_64판은 x86-64-v3 CPU가 필요합니다. Arm(aarch64)판은 UEK로만 돌아갑니다.
- 메이저 버전 업그레이드는 Leapp으로 할 수 있지만, 9의 최신 업데이트 릴리스에서 10의 최신 버전으로 가는 경로만 지원합니다.
- yum 서버의 Latest 채널에는 최신 업데이트 릴리스의 패키지와 그 뒤의 수정만 남고, 이전 패키지는 Archive 채널로 옮겨집니다.
