Bodhi Linux is a lightweight distribution that rests on two ideas: a minimal base system and its own Moksha desktop. Each major version is built on the newest Ubuntu LTS of its time; the current one is Bodhi Linux <Latest slug="bodhi-linux" />. The name comes from the Sanskrit word for enlightenment.

### Highlights

- **The Moksha desktop.** Moksha carries on the Enlightenment e17 desktop that Bodhi started with, adding new features and pieces from later Enlightenment releases. Rather than hiding settings, it exposes all of them, and themes, backgrounds and modules let you change both its look and what it does.
- **A minimal starting point.** The default set is little more than a terminal, a web browser, a file manager, a text editor and an image viewer. The idea is that you add the rest yourself with `apt`, Synaptic or the Bodhi AppCenter. Web Browser Manager makes it easy to switch to another browser.
- **“Semi-rolling” releases.** You only reinstall when a new major version arrives, roughly every two years. Until then the current major version gets application updates through the AppCenter as well as security updates; older major versions get security updates only.

### Editions and variants

- **Standard** is the minimal default image.
- **HWE** is Standard with a newer kernel, and **s76** goes further still for very recent hardware.
- **AppPack** adds a selection of themes and applications such as LibreOffice and GIMP.
- There is also a 32-bit **Legacy** image, and a **Debian Edition** built on Debian, released as a beta.

### Who it suits

- Anyone who wants to give an old or low-powered PC a light, quick system
- People who would rather start small and add only the applications they choose
- Users who enjoy tweaking every setting and detail of their desktop

### Good to know

- Moving to a new major version means a fresh install, not an in-place upgrade.
- The wiki describes a major release about every two years, but after 7.0 (August 2023, based on Ubuntu 22.04), Bodhi 8 was still in development as of the project’s March 2025 update. Check the official news before you download.
- Bodhi is a small project with only a few active team members. Help comes from the wiki, the forums and the Discord chat.

### A short history

Bodhi began with the Enlightenment e17 desktop and created Moksha to carry it forward. From 1.x on Ubuntu 10.04 to 7.0 on Ubuntu 22.04, each major version has been based on the newest Ubuntu LTS of its day.
