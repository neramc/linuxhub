Xubuntu is the official Ubuntu flavor with the Xfce desktop, made by volunteers. It follows Ubuntu’s schedule, with a new version every six months and a long-term support (LTS) release every two years; the current one is Xubuntu <Latest slug="xubuntu" />. Its aim is a light desktop that you can configure extensively.

### Highlights

- **Apps picked around Xfce.** Xfce’s own Thunar file manager, Mousepad editor and Parole media player are joined by MATE’s Atril document viewer and GNOME tools such as Disks. LibreOffice and GIMP are installed by default.
- **The same base as Ubuntu.** Packages and security updates come from the Ubuntu archive, and since 24.04 Xubuntu uses the same Flutter-based installer as Ubuntu. Firefox and Thunderbird ship as snaps.
- **X11 still available.** Ubuntu’s GNOME session is now Wayland-only, but the Xfce session can still run on X.org. Wayland support has been growing since Xfce 4.20.
- **Support periods.** LTS releases get three years of updates, interim releases nine months.

### Editions and variants

- **Desktop** is the full image, with office, graphics and media apps included.
- **Minimal**, available since 24.04, keeps only the essentials and leaves the choice of apps to you. A Minimal image for 64-bit RISC-V is offered as experimental.

### Who it suits

- People whose PC has too little memory for Ubuntu Desktop; Ubuntu itself points lower-spec machines to its flavors and says Xubuntu runs with 2 GB of RAM or more
- Anyone who wants to rearrange the panels and desktop settings to their liking
- Users who want Ubuntu’s archive and release schedule with a lighter desktop on top

### Good to know

- LTS support lasts three years, shorter than Ubuntu Desktop’s five, so plan your move to the next LTS.
- The indicator plugin is no longer on the default panel. If an app with an old-style tray icon doesn’t show up, add the plugin back in the panel preferences.
- The installer has known issues, such as the GRUB menu not appearing after a dual-boot install, so check the known issues in the release notes before you start.

### A short history

The first release was Xubuntu 6.06 “Dapper Drake” on 1 June 2006. The 26.04 LTS release in April 2026 marked twenty years of the flavor and shipped wallpapers chosen in community contests.
