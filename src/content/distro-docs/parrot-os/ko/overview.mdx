ParrotOS는 보안 점검과 개인정보 보호, 소프트웨어 개발을 함께 염두에 둔 Debian 기반 배포판입니다. 창시자 Lorenzo Faletra가 지금도 개발을 이끌고, 영국에 등록된 공익 회사 Parrot Security CIC가 프로젝트를 운영합니다. 바탕은 Debian 안정판이지만 보안 도구처럼 급한 업데이트는 Parrot이 직접 들여와 계속 올려 주는 반(半)롤링 방식이며, 지금 최신 버전은 Parrot <Latest slug="parrot-os" />입니다.

### 특징

- **점검부터 보고서까지 한 시스템에서.** 보안 도구만 담는 다른 점검용 배포판과 달리 문서 작성과 개발에 쓰는 일상 앱도 함께 넣었습니다. 노트북 한 대와 Parrot만으로 점검을 시작해 보고서까지 마칠 수 있게 하는 것이 목표입니다.
- **샌드박스와 강화 설정.** AppArmor 프로필과 Firejail 같은 강화 설정이 기본으로 들어 있습니다. 데스크톱 전체를 root로 로그인할 수 없고, 브라우저나 문서 뷰어 같은 앱은 높은 권한으로 실행되지 않습니다. 대신 root 터미널은 언제든 열 수 있습니다.
- **꺼진 채로 시작하는 서비스와 자동 마운트.** 미리 설치된 네트워크 서비스는 모두 꺼져 있어 필요할 때 직접 켜야 합니다. 포렌식 작업을 위해 디스크 자동 마운트도 기본으로 꺼 두었습니다.
- **과정이 보이는 업데이트.** 일주일에 한 번 업데이트를 알려 주는 도구는 진행 막대 대신 `apt` 출력을 그대로 보여 줍니다. 시스템 전체 업데이트에는 의존성을 안전하게 처리해 주는 `parrot-upgrade`를 권합니다.
- **AnonSurf.** 지원되는 TCP 연결과 DNS 조회를 Tor로 돌려 보내는 Parrot의 도구입니다. VPN이 아니어서 UDP 트래픽은 Tor를 거치지 않습니다.

### 에디션과 변형

- **Security**는 침투 테스트와 레드 팀 작업용으로, 보안 도구 전체를 담은 `parrot-tools-full` 메타패키지가 들어 있습니다.
- **Home**은 일상 사용과 개인정보 보호, 개발을 위한 판으로 보안 도구가 빠져 있습니다. 필요한 도구만 골라 설치해 가벼운 점검 환경을 꾸밀 수 있습니다.
- **HTB**는 Hack The Box와 CTF 참가자를 위해 자주 쓰는 도구와 작업 흐름을 미리 맞춘 판입니다.
- 세 판 모두 기본 데스크톱은 KDE Plasma입니다. 최신 CPU 명령어 세트(x86-64-v3 등)에 맞춰 다시 빌드한 Tuned 판, Raspberry Pi용 이미지, 가상 머신·Docker·WSL용 판도 있습니다.

### 이런 분께 맞습니다

- 점검 도구와 일상 업무 앱을 한 시스템에서 쓰고 싶은 보안 전문가
- Hack The Box나 CTF로 실습하는 학생
- 보안 설정이 단단한 Debian 기반 데스크톱을 원하는 개발자(Home 에디션)

### 알아 둘 점

- Windows와 함께 설치하는 공식 안내는 UEFI 설정에서 Secure Boot와 CSM을 먼저 끄라고 합니다.
- 공식 저장소 말고 다른 저장소를 더하거나 고치는 것은 필요하지도 않고 권하지도 않습니다.
- Parrot 6 "Lorykeet"에서 Debian 13 기반의 Parrot 7 "Echo"로 가는 것처럼 큰 버전이 바뀔 때는 새로 설치하기를 권합니다. 제자리 업그레이드도 `parrot-upgrade`로 할 수 있지만 설정 파일이 덮어쓰일 수 있으니 먼저 백업합니다.
- 자동 마운트를 꺼 두었어도 실수로 직접 마운트하는 것까지 막지는 못합니다. 포렌식 작업에는 하드웨어 쓰기 차단 장치를 권합니다.

### 간단한 역사

Parrot은 같은 창시자가 운영하던 커뮤니티 포럼 Frozenbox에서 시작해 2013년 4월 10일 처음 공개되었습니다. 프로젝트 본부는 이탈리아 팔레르모에 있습니다.
