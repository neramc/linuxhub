이 가이드는 가장 많이 쓰는 **Fedora Workstation <Latest slug="fedora" />**(GNOME)을 기준으로 합니다. KDE Plasma Desktop 에디션이나 다른 Spin도 과정은 거의 같습니다.

## 시작하기 전에

- **권장 사양**: 2GHz 이상의 듀얼코어 64비트 CPU, 메모리 4GB, 저장공간 20GB 이상. UEFI 펌웨어를 쓰는 PC를 권장합니다.
- **백업**: 설치 과정에서 디스크를 지울 수 있습니다. 중요한 파일은 외장 디스크나 클라우드에 먼저 백업하세요.
- **인터넷 연결**: 설치 자체는 오프라인으로도 되지만, 설치 직후 업데이트와 드라이버 설치에 필요합니다.

## 1. 설치 이미지 내려받기

[다운로드 패널](../#download)에서 **Workstation**, 아키텍처(대부분의 PC는 **x86_64**)를 고르면 가장 가까운 공식 서버에서 내려받습니다. 현재 기본 이미지는 <IsoName slug="fedora" />입니다.

<Callout type="tip" title="더 쉬운 방법: Fedora Media Writer">
  Fedora가 만든 **Fedora Media Writer**는 이미지를 내려받고 USB에 쓰는 일을 한 번에 해 줍니다. Windows·macOS용 설치 파일은 Fedora 공식 다운로드 페이지에, Linux용은 Flathub에 있습니다. 이 도구를 쓰면 2·3단계를 건너뛰어도 됩니다.
</Callout>

## 5. Fedora 설치하기

라이브 데스크톱의 환영 창에서 **Install Fedora…**(또는 Dash의 **Install to Hard Drive**)를 누르면 설치 프로그램 **Anaconda**가 열립니다. 화면 이름은 버전에 따라 조금씩 다를 수 있습니다.

<Steps>

1. **언어 선택**: 설치 과정과 시스템에서 쓸 언어를 고릅니다. 한국어를 고르면 설치 후 한글 입력기(IBus 한글)도 함께 설정됩니다.
2. **설치 방법 선택**: 설치할 디스크를 고른 뒤 방법을 정합니다.
   - **전체 디스크 사용**: 선택한 디스크의 모든 데이터를 지우고 Fedora만 설치합니다.
   - **다른 운영체제와 디스크 공유**: Windows 등 기존 시스템을 그대로 두고, 미리 비워 둔 빈 공간에 설치합니다(듀얼 부팅).
   - 파티션을 직접 나누려면 고급 옵션의 **저장소 편집기**를 씁니다. Fedora는 기본으로 Btrfs 파일 시스템을 쓰고 `/`와 `/home`을 하위 볼륨으로 나눕니다.
3. **디스크 암호화**(선택): **데이터 암호화**를 켜고 암호를 정하면 LUKS 전체 디스크 암호화가 적용됩니다. 노트북이라면 켜 두기를 권장합니다. 이 암호를 잊으면 데이터를 복구할 수 없습니다.
4. **검토 및 설치**: 선택한 내용을 확인하고 **데이터 지우기 및 설치**(또는 **설치**)를 누릅니다. 설치는 보통 5~15분 걸립니다.
5. **다시 시작**: 완료 화면에서 **재부팅**을 누르고, 화면이 꺼지면 USB를 뽑습니다.

</Steps>

### 처음 켤 때 설정

다시 시작하면 GNOME 초기 설정이 이어집니다.

<Steps>

1. **개인정보**: 위치 서비스와 자동 문제 보고를 켤지 정합니다.
2. **서드파티 저장소**: 켜면 NVIDIA 드라이버, Steam, Google Chrome 같은 외부 소프트웨어와 전체 Flathub를 GNOME 소프트웨어에서 바로 설치할 수 있습니다. 일반 사용자라면 켜는 편이 편리합니다.
3. **온라인 계정**(선택): Google, Microsoft, Nextcloud 계정을 연결하면 캘린더·연락처·파일이 연동됩니다.
4. **사용자 정보와 암호**: 이름, 사용자 이름, 로그인 암호를 정합니다. 이 계정은 `sudo`로 관리자 권한을 쓸 수 있습니다.

</Steps>

<Anchor id="after-install" />
## 6. 설치 후 할 일

### 시스템 업데이트

설치 이미지가 나온 뒤에도 업데이트가 계속 나옵니다. GNOME 소프트웨어의 **업데이트** 탭을 쓰거나 터미널에서 실행하세요.

```bash
sudo dnf upgrade --refresh
```

### 미디어 코덱(RPM Fusion)

Fedora에는 특허 문제가 있는 코덱이 빠져 있어 일부 동영상이 재생되지 않을 수 있습니다. 커뮤니티 저장소 **RPM Fusion**을 추가하면 해결됩니다.

```bash
sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm \
  https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
sudo dnf swap ffmpeg-free ffmpeg --allowerasing
sudo dnf install @multimedia --setopt="install_weak_deps=False" --exclude=PackageKit-gstreamer-plugin
```

### NVIDIA 그래픽 카드

NVIDIA GPU의 성능을 제대로 쓰려면 RPM Fusion의 독점 드라이버가 필요합니다. RPM Fusion을 추가한 뒤 다음을 실행하고, 설치가 끝나면 커널 모듈이 빌드될 때까지 몇 분 기다렸다가 다시 시작하세요.

```bash
sudo dnf install akmod-nvidia
```

<Callout type="warning" title="Secure Boot를 켠 경우">
  직접 빌드된 드라이버 모듈은 서명 키를 펌웨어에 등록해야 로드됩니다. 키를 등록하는 방법은 [RPM Fusion의 NVIDIA 안내](https://rpmfusion.org/Howto/NVIDIA)에 있는 Secure Boot 항목을 따르세요.
</Callout>

### Flathub 앱

초기 설정에서 서드파티 저장소를 켰다면 GNOME 소프트웨어에서 Flathub 앱을 바로 설치할 수 있습니다. 직접 추가하려면 다음을 실행합니다.

```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```

## 문제 해결

- **USB로 부팅되지 않음**: 부팅 메뉴에서 이름에 **UEFI**가 붙은 항목을 고르세요. Rufus로 만들었다면 **DD 이미지 모드**로 다시 만들어 보세요.
- **설치 전후로 화면이 검게 멈춤**(주로 NVIDIA): GRUB 메뉴에서 <Kbd>e</Kbd>를 눌러 `linux`로 시작하는 줄 끝에 `nomodeset`을 붙이고 <Kbd>Ctrl</Kbd>+<Kbd>X</Kbd>로 부팅하세요. 설치를 마친 뒤 NVIDIA 드라이버를 설치하면 이 옵션은 더 필요 없습니다.
- **부팅 메뉴에 Windows가 없음**: Windows의 빠른 시작이 꺼져 있는지 확인한 뒤 `sudo grub2-mkconfig -o /boot/grub2/grub.cfg`로 부팅 메뉴를 다시 만드세요.
- **Wi-Fi가 잡히지 않음**: 일부 Broadcom 무선 칩은 RPM Fusion의 `broadcom-wl` 패키지가 필요합니다. 유선 연결이나 휴대폰 USB 테더링으로 먼저 인터넷에 연결하세요.

## 다음 버전으로 업그레이드하기

새 버전이 나오면 GNOME 소프트웨어가 업그레이드를 알려 줍니다. 각 버전은 약 13개월 동안 지원되므로, 지원이 끝나기 전에 업그레이드하세요. 터미널을 쓰는 방법은 [Fedora의 업그레이드 안내](https://docs.fedoraproject.org/en-US/quick-docs/upgrading-fedora-offline/)에 있습니다.
