Windows와 macOS는 화면 모양이 운영체제에 붙어 있지만, 리눅스에서는 화면을 담당하는 **데스크톱 환경(desktop environment, DE)** 이 따로 떨어진 부품입니다. 그래서 같은 배포판이라도 데스크톱을 바꾸면 전혀 다른 운영체제처럼 보이고, 마음에 들지 않으면 배포판을 그대로 둔 채 데스크톱만 바꿀 수도 있습니다.

이 장에서는 데스크톱 환경이 무엇으로 이루어지는지, 대표적인 데스크톱의 특징, 키보드 중심의 타일링 창 관리자, 그리고 다른 데스크톱을 안전하게 시험하는 방법을 정리합니다.

## 데스크톱 환경은 무엇으로 이루어지나

데스크톱 환경은 여러 프로그램을 한 벌로 맞춰 놓은 묶음입니다.

- **창 관리자(window manager)** 또는 **컴포지터(compositor)**: 창을 그리고 옮기고 겹치는 방식을 정합니다.
- **패널과 앱 실행기**: 작업 표시줄, 시작 메뉴, 시스템 트레이, 알림.
- **설정 앱**: 디스플레이, 키보드, 네트워크, 테마를 한곳에서 바꿉니다.
- **기본 앱**: 파일 관리자, 터미널, 텍스트 편집기, 이미지 보기 등.

여기에 **디스플레이 관리자(display manager)**, 즉 로그인 화면이 붙습니다. GNOME은 GDM, KDE Plasma는 SDDM을 주로 쓰고, LightDM처럼 특정 데스크톱에 묶이지 않은 것도 있습니다. 데스크톱이 여러 개 설치되어 있으면 로그인 화면에서 어느 **세션(session)** 으로 들어갈지 고를 수 있습니다.

데스크톱마다 바탕이 되는 **툴킷(toolkit)** 이 다릅니다. GNOME, Xfce, Cinnamon, MATE, Budgie, Pantheon은 **GTK**를, KDE Plasma와 LXQt는 **Qt**를 쓰고, COSMIC은 Rust용 **iced**를 씁니다. 어떤 데스크톱에서든 다른 툴킷으로 만든 앱을 실행할 수 있지만, 테마와 대화상자 모양이 조금 어색해 보일 수 있습니다. 여러 데스크톱이 freedesktop.org의 공통 규격을 따르기 때문에 앱 메뉴, 아이콘, 자동 실행 같은 기본 동작은 대부분 호환됩니다.

<Callout type="note" title="창 관리자와 컴포지터">
  X11에서는 창 관리자, 컴포지팅 관리자, 디스플레이 서버가 따로 나뉘어 있었습니다. Wayland에서는 컴포지터 하나가 이 역할을 모두 맡습니다. 이 차이는 [X11과 Wayland](../display-servers/) 장에서 자세히 다룹니다.
</Callout>

## 한눈에 비교하기

| 데스크톱 | 툴킷 | 기본 화면 구성 | 자원 사용(대략) | 이런 분께 맞습니다 | 대표 배포판 |
|---|---|---|---|---|---|
| GNOME | GTK | 상단 바와 활동 개요 화면 | 보통~많음 | 단순하고 집중된 작업 흐름, 터치패드 제스처 | Fedora Workstation, Ubuntu |
| KDE Plasma | Qt | 하단 패널과 시작 메뉴 | 보통 | 세세하게 꾸미고 싶은 분, Windows에서 넘어온 분 | Kubuntu, Fedora KDE |
| Xfce | GTK | 패널과 메뉴, 전통적 구성 | 적음 | 오래된 PC, 가볍고 안정적인 환경 | Xubuntu, Linux Mint Xfce |
| Cinnamon | GTK | 하단 패널과 시작 메뉴 | 보통 | Windows와 비슷한 화면을 원하는 입문자 | Linux Mint |
| MATE | GTK | GNOME 2 방식의 위·아래 패널 | 적음 | 고전적인 데스크톱을 좋아하는 분 | Ubuntu MATE |
| LXQt | Qt | 하단 패널과 메뉴 | 아주 적음 | 사양이 낮은 PC | Lubuntu |
| Budgie | GTK | 패널, Raven 사이드바, 레이아웃 선택 | 보통 | 깔끔하면서 손쉽게 꾸미고 싶은 분 | Ubuntu Budgie |
| COSMIC | iced | 패널과 독, 선택형 타일링 | 보통 | 마우스와 타일링을 함께 쓰고 싶은 분 | Pop!\_OS |
| Pantheon | GTK | 상단 바와 하단 독 | 보통 | 단순하고 정돈된 디자인 | elementary OS |

<Callout type="tip" title="자원 사용은 상대적인 비교입니다">
  표의 자원 사용은 대략적인 순서일 뿐입니다. 실제 메모리 사용량은 배포판의 기본 설정, 버전, 켜 둔 앱에 따라 크게 달라집니다. 브라우저 탭 몇 개가 데스크톱 자체보다 메모리를 더 쓰는 경우도 흔합니다.
</Callout>

## 주요 데스크톱 환경

### GNOME

<Kbd>Super</Kbd> 키 하나로 열리는 **활동 개요(Activities)** 화면에서 앱 실행, 창 전환, 검색을 모두 처리하는 단순한 데스크톱입니다. 작업 공간을 넉넉하게 쓰도록 설계했고, 기본 앱들이 같은 디자인 원칙을 따릅니다. Fedora Workstation, Ubuntu, Debian, RHEL 등 여러 배포판의 기본 데스크톱이며, 배포판에 따라 기본 모양을 조금 바꿔서 넣기도 합니다. 모양을 더 바꾸고 싶다면 확장(extension)을 설치합니다. Wayland에서 동작하며, X11 앱은 XWayland로 실행합니다.

### KDE Plasma

기본 모양은 하단 패널과 시작 메뉴로 Windows와 비슷하지만, 패널 위치부터 색상, 글꼴, 위젯까지 거의 모든 것을 바꿀 수 있는 것이 가장 큰 특징입니다. 입력하는 대로 앱·파일·계산 결과를 찾아 주는 **KRunner**, 배포판 패키지와 Flatpak, Snap을 한곳에서 관리하는 **Discover**를 갖추고 있습니다. Wayland 세션이 기본이며, KDE는 X11 세션을 더 이상 포함하지 않는 방향으로 전환하고 있습니다.

### Xfce

빠르고 자원을 적게 쓰는 것을 목표로 하는 GTK 기반의 가벼운 데스크톱입니다. 창 관리자, 패널, 파일 관리자 같은 구성 요소가 따로따로 패키지로 나뉘어 있어 필요한 것만 골라 쓸 수 있습니다. 오랫동안 크게 바뀌지 않은 전통적인 화면이라 익숙하고 안정적입니다. Wayland 지원은 아직 실험 단계입니다.

### Cinnamon

Linux Mint가 직접 개발하는 데스크톱으로, 전통적인 화면 배치에 현대적인 효과를 더했습니다. GNOME에서 갈라져 나왔지만 지금은 독립된 데스크톱입니다. 오랫동안 X11 위에서 동작해 왔고, Cinnamon 6.0부터 Wayland 세션을 실험 기능으로 함께 제공하기 시작했습니다.

### MATE와 LXQt

**MATE**는 GNOME 2를 이어 가는 프로젝트로, 위·아래 패널을 둔 고전적인 화면을 유지하면서 가볍게 동작합니다. **LXQt**는 Qt로 만든 가벼운 데스크톱으로, 시스템을 느리게 만들지 않으면서 현대적인 모양을 내는 것을 목표로 합니다. 둘 다 오래된 노트북이나 메모리가 적은 PC에 잘 맞습니다. LXQt는 X11에서는 창 관리자를 바꿔 쓸 수 있고, 여러 Wayland 컴포지터 위에서도 실행할 수 있습니다.

### Budgie

Solus에서 시작해 지금은 Buddies of Budgie가 만드는 GTK 기반 데스크톱입니다. 알림과 위젯을 모아 둔 **Raven** 사이드바가 특징이고, 설정에서 전통적인 배치, Unity 같은 배치, macOS 같은 배치 중에서 고를 수 있습니다. Budgie 10.10부터 Wayland로 옮겨 가면서 X11 지원을 정리했습니다.

### COSMIC

System76이 Pop!\_OS를 위해 만든 데스크톱으로, 처음에는 GNOME을 크게 고친 형태였다가 Rust 언어로 처음부터 다시 만들었습니다. 처음부터 Wayland 전용으로 설계했고, 마우스로 쓰는 일반 창 배치에 자동 **타일링(tiling)** 을 켜고 끌 수 있습니다. Fedora에도 COSMIC 에디션이 있습니다.

### Pantheon

elementary OS의 데스크톱으로, Vala와 GTK, elementary의 Granite 라이브러리로 만들었습니다. 상단 바와 하단 독으로 이루어진 단순하고 일관된 디자인을 중시합니다. elementary OS는 "보안 세션(Secure Session)"을 중심으로 Wayland 전환을 진행하고 있습니다.

## 타일링 창 관리자와 컴포지터

대부분의 데스크톱은 창을 종이처럼 겹쳐 놓는 **스태킹(stacking, floating)** 방식을 씁니다. 반면 **타일링(tiling)** 방식은 창이 서로 겹치지 않게 화면을 자동으로 나눠 채우고, 주로 키보드 단축키로 조작합니다. 두 방식을 오갈 수 있는 것은 **동적(dynamic)** 창 관리자라고 부릅니다.

| 이름 | 디스플레이 서버 | 특징 |
|---|---|---|
| i3 | X11 | 처음부터 새로 만든 타일링 창 관리자. 설정 파일이 단순하고 문서가 잘 정리되어 있습니다 |
| Sway | Wayland | i3와 호환되도록 만든 Wayland 컴포지터. 기존 i3 설정을 거의 그대로 쓸 수 있습니다 |
| Hyprland | Wayland | 동적 타일링에 애니메이션, 둥근 모서리, 흐림 효과를 더했고 플러그인으로 확장합니다 |
| niri | Wayland | 창을 옆으로 길게 이어 붙이고 스크롤하며 이동하는 타일링 컴포지터 |

i3와 Sway의 설정은 이런 모양입니다. `$mod`는 주로 <Kbd>Super</Kbd> 키(Mod4)로 정합니다. i3의 기본값은 <Kbd>Alt</Kbd>(Mod1)입니다.

```text
set $mod Mod4
bindsym $mod+Return exec foot
bindsym $mod+h focus left
bindsym $mod+1 workspace number 1
bindsym $mod+Shift+q kill
```

타일링 창 관리자는 창 관리만 맡는 경우가 많아서, 상태 표시줄, 앱 실행기, 알림, 화면 잠금, 배경 화면 같은 나머지 부품은 직접 골라 설치하고 설정해야 합니다. 그만큼 가볍고 내 손에 꼭 맞게 만들 수 있지만 처음 구성하는 데 시간이 듭니다.

<Callout type="tip" title="타일링을 가볍게 맛보려면">
  처음부터 전부 구성하기 부담스럽다면 타일링이 들어 있는 데스크톱(COSMIC)이나, Sway를 미리 구성해 둔 배포판 에디션(Fedora Sway Atomic 등)으로 시작해 보세요. 카탈로그에서 [i3](../../distros/?desktop=i3), [Sway](../../distros/?desktop=sway), [Hyprland](../../distros/?desktop=hyprland)를 쓰는 배포판을 찾아볼 수 있습니다.
</Callout>

## 다른 데스크톱 시험해 보기

데스크톱을 바꾸는 방법은 위험이 적은 순서로 세 가지가 있습니다.

<Steps>

1. **라이브 USB로 써 보기**: Kubuntu, Xubuntu, Fedora KDE처럼 원하는 데스크톱을 기본으로 쓰는 배포판을 USB로 부팅해 설치 없이 써 봅니다.
2. **가상 머신(virtual machine)에서 써 보기**: GNOME Boxes나 VirtualBox에 설치해 지금 시스템을 건드리지 않고 오래 써 봅니다.
3. **지금 시스템에 추가 설치하기**: 아래 명령으로 데스크톱을 설치한 뒤 로그아웃하고, 로그인 화면에서 세션을 골라 들어갑니다. GDM에서는 사용자를 고른 뒤 나타나는 설정(톱니바퀴) 아이콘에서 고릅니다.

</Steps>

<Tabs>
<Tab label="Ubuntu/Debian" open>

Ubuntu에서는 공식 플레이버의 메타패키지를, Debian에서는 `task-` 패키지를 설치합니다.

```bash
# Ubuntu: KDE Plasma(Kubuntu), Xfce(Xubuntu)
sudo apt install kubuntu-desktop
sudo apt install xubuntu-desktop

# Debian: KDE Plasma, Xfce
sudo apt install task-kde-desktop
sudo apt install task-xfce-desktop
```

설치 도중 기본 로그인 화면(디스플레이 관리자)을 고르라는 창이 나오면 지금 쓰는 것을 그대로 골라도 됩니다.

</Tab>
<Tab label="Fedora">

설치할 수 있는 데스크톱 목록을 확인한 뒤 앞에 `@`를 붙여 설치합니다.

```bash
dnf environment list --available | grep -i desktop
sudo dnf install @kde-desktop-environment
```

</Tab>
<Tab label="Arch">

```bash
# KDE Plasma
sudo pacman -S plasma-meta
# Xfce와 추가 플러그인
sudo pacman -S xfce4 xfce4-goodies
# GNOME
sudo pacman -S gnome
```

</Tab>
</Tabs>

<Callout type="warning" title="데스크톱을 여러 개 섞을 때">
  전체 데스크톱 패키지는 설정 앱, 파일 관리자, 테마까지 함께 설치합니다. 여러 데스크톱을 한 시스템에 두면 앱 메뉴에 같은 종류의 앱이 겹쳐 보이고, 테마나 설정이 서로 영향을 줄 수 있으며, 나중에 깔끔하게 지우기도 어렵습니다. 오래 쓸 생각이라면 가상 머신이나 라이브 USB로 먼저 확인하고, 마음에 드는 데스크톱을 기본으로 쓰는 배포판을 새로 설치하는 편이 깔끔합니다.
</Callout>

## 어떤 데스크톱을 고를까

- **처음이고 Windows가 익숙하다면** Cinnamon이나 KDE Plasma가 가장 덜 낯섭니다.
- **단순하고 방해받지 않는 화면을 원한다면** GNOME이나 Pantheon을 써 보세요.
- **PC 사양이 낮다면** Xfce, MATE, LXQt가 부담이 적습니다.
- **고해상도 화면, 모니터마다 다른 배율, 터치패드 제스처가 중요하다면** Wayland가 기본인 GNOME, KDE Plasma, COSMIC이 유리합니다.
- **키보드만으로 빠르게 작업하고 싶다면** Sway, Hyprland, i3 같은 타일링 환경을 시험해 보세요.
