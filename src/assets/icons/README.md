# Icons

Symbolic icons copied from upstream GNOME sources, recolored to
`currentColor`, with editor metadata and inline styles stripped, then
optimized with SVGO (`scripts/assets/svgo.config.mjs`).

- **Adwaita icon theme 51.0**: https://download.gnome.org/sources/adwaita-icon-theme/51/
  (sha256 `ba561cf3c96305a47179fa5605856ad695c9238ea07f7093aebd9ba80c4e323b`).
  License: CC BY-SA 3.0 or LGPL-3.0, © GNOME Project.
- **libadwaita 1.10.0**: `external.svg` comes from `adw-external-link.svg`. License: LGPL-2.1-or-later.
