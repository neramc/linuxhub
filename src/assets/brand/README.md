# Site logo: Tux

`tux.svg` (also served as `public/favicon.svg`) is the Linux mascot Tux, taken
unmodified from [File:Tux.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Tux.svg)
and only losslessly optimized with `scripts/assets/svgo.config.mjs`.
`public/apple-touch-icon.png` is a 180 px raster of the same file on a light
tile, made with `scripts/assets/brand-icons.ts`.
