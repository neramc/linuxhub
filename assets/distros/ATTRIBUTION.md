# Distro Logo Attribution

Every logo stored in this directory MUST have a row here **in the same commit**
(see `.ai/data-sources.md`). Real official brand SVGs only — retrieved from
Wikimedia Commons (`Special:FilePath`). Logos are trademarks of their
respective projects and are used here as nominative references to identify
each distribution, unmodified (no recoloring, no distortion). If a project
objects or forbids redistribution, the file is removed and the site links out
instead. Final per-file license verification against each Commons file page
and each project's brand guidelines is re-checked at the Phase 6 quality gate.
