# CLAUDE.md — Linuxhub

Linuxhub is a fast, bilingual (Korean default at `/`, English at `/en/`) catalog
of ~50 popular Linux distributions, built with **Astro 7** and a **GNOME
libadwaita** look (Flathub-like). Every distro has a short overview, an
official-doc-level install guide, its official logo, and a guided download
(version → edition → arch → format → mirror) that only uses **official
mirrors/CDNs** and recommends the nearest mirror from the visitor's IP.
Release data refreshes automatically every 6 hours via GitHub Actions.

The approved plan lives in `docs/plan.md` (Korean). Decisions are logged in
`docs/decisions.md`. Read both before changing architecture.

## Stack (changes need a new ADR in `docs/decisions.md`)

| Layer | Choice |
|---|---|
| Framework | Astro 7, `output: "static"`; the only on-demand route is `src/pages/api/geo.ts` |
| Package manager / scripts | Bun (single app, no monorepo). Astro itself runs on Node ≥ 22.12 |
| Content | Content Layer collections in `src/content.config.ts` (`z` from `astro/zod`, Zod 4) + `@astrojs/mdx` |
| Styling | Plain CSS with libadwaita tokens (`src/styles/`), Astro scoped styles. No Tailwind, no UI framework runtime |
| Client JS | Small vanilla TS islands only where needed (download wizard, filters, search, quiz, compare, copy, theme) |
| Search | `astro-pagefind` (index built in `astro:build:done`) with a custom Adwaita dialog |
| Deploy | Vercel via `@astrojs/vercel` (`imageService: false`, `staticHeaders: true`), region `icn1` |
| Data refresh | `scripts/sync/` run by `.github/workflows/sync.yml`, writes `src/data/**` and commits |
| Lint / tests | Biome, Vitest (`tests/`, `scripts/**/*.test.ts`), Playwright + axe (`e2e/`) |

## Hard rules

1. **Near-zero JS.** Pages are static HTML. Add client JS only for real
   interaction, as a small vanilla module. Never add React/Svelte/Vue runtimes.
2. **CSP is on** (`security.csp`). No inline `style=""` attributes, no inline
   event handlers, no Shiki (Prism only), no `<ClientRouter/>`. Use native CSS
   cross-document view transitions.
3. **Adwaita design only.** Use the tokens in `src/styles/tokens.css` and the
   components in `src/components/adw/`. Do not invent colors, radii or shadows;
   do not restyle a component per page. New visual patterns go into the
   component set first.
4. **i18n.** No hardcoded UI strings: use `src/i18n/` dictionaries (`ko`,
   `en`). Every page exists in both locales via the `[...locale]` route param.
5. **Official sources only.** Downloads, checksums and mirrors come from the
   official project. Checksums are always shown from the official origin host.
   `src/data/**` is generated by `bun run sync` — never edit it by hand.
6. **Polite fetching.** Sync respects robots.txt and Crawl-delay, sends the
   `LinuxhubBot` User-Agent, paces per host, uses ETag/If-Modified-Since.
   Never scrape DistroWatch; the distro list is editorial.
7. **Content.** Paraphrase official docs — never copy verbatim. Every
   overview/install doc lists `sources` and `lastReviewed` in frontmatter.
   Versions, filenames and checksums inside docs come from data components,
   never hand-typed. Korean and English ship together.
8. **Logos.** Official, unmodified (no recoloring). Record source URL,
   license and trademark policy per logo.
9. **Privacy.** `/api/geo` returns country/coordinates with
   `Cache-Control: private, no-store` and never logs them.

## Commands (run before every commit)

```bash
bun run lint      # Biome (bun run format to autofix)
bun run check     # astro check + scripts typecheck
bun run test      # vitest
bun run build     # astro build (+ pagefind, sitemap, vercel output)
bun run test:e2e  # Playwright + axe against the production build (UI changes)
```

## Git

One completed task = one commit, Conventional Commits
(`feat(web): …`, `feat(sync): …`, `docs: …`, `chore(data): sync …`).
Develop on the assigned branch; production deploys from `main`.
